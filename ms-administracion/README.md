# ms-administracion — Microservicio de administración

## Rutas
- GET /admin/usuarios
- PATCH /admin/usuarios/:id
- GET /admin/roles
- POST /admin/roles
- GET /admin/permisos
- GET /estadisticas

## Origen del código
api/rutas/admin.js + reportes.js

## Desarrollo
```bash
npm install
npm run dev     # http://localhost:3006
```

## Variables de entorno
```bash
cp .env.example .env
```
