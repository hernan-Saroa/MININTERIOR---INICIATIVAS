# ms-autenticacion — Microservicio de autenticación

## Rutas
- POST /auth/login
- POST /auth/registro
- POST /auth/salir
- GET /auth/sesion
- POST /auth/recuperar
- POST /auth/restablecer

## Origen del código
api/rutas/auth.js + api/auth/

## Desarrollo
```bash
npm install
npm run dev     # http://localhost:3001
```

## Variables de entorno
```bash
cp .env.example .env
```
